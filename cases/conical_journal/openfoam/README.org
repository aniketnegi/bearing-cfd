* Versioning boundary

Commit files required to define or regenerate a case: dictionaries, initial
uniform fields, source code, run procedures, parameter sources, study
manifests, and compact results.  Prefer a small stage overlay when only one or
two dictionaries change; do not duplicate a complete case for a parameter
toggle.

Do not commit =constant/polyMesh=, mapped or solved fields, numeric time
directories, =processor*=, =postProcessing=, VTK exports, ordinary logs, or
ParaView markers.  Case procedures create those below =out/=.
