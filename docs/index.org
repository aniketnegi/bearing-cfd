* Purpose

This notebook explains how the geometry and meshes are constructed.  It assumes
familiarity with Python and basic journal-bearing physics; it concentrates on
programmatic B-rep modelling, mesh topology, data exchange, and solver hand-off.

* Scope boundary

This repository currently proves geometry, mesh topology/quality, and static
solver-neutral transfer. Patch names describe intended physical roles, but they
are not yet numerical CFD boundary conditions. In particular, =pressure_feed= is
an inlet candidate and the two axial end patches are outlet candidates; no
pressure, flow rate, journal speed, lubricant model, initialization, or
iteration is assigned in this stage.
