* Interpretation

The native geometry is accepted for BREP-based Gmsh/OpenCASCADE work.  STEP
remains an engineering exchange target for external CAD tools, but these files
do not satisfy the project's strict thin-film regression gate on the recorded
software stack.  The gate is not relaxed to convert a format-specific failure
into a geometry PASS.
