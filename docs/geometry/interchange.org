#+TITLE: CAD Interchange: Native BREP and STEP
#+UPDATED_AT: [2026-08-02 Sun]
#+STARTUP: overview
#+OPTIONS: toc:2 num:nil

* Format roles

| Format | Role | Acceptance |
|---+---+---|
| native OCCT BREP | geometry input to Gmsh/OpenCASCADE | mandatory for geometry publication |
| STEP | inspection and engineering exchange | checked independently; rejected files are excluded from the accepted directory |

Native BREP stays within the OCCT topology model used by build123d and Gmsh.
STEP passes through a neutral exchange representation and may reconstruct
curved intersections with different tolerances.

* Native BREP

=film_unsplit.brep= contains the connected lubricant volume.
=film_zones.brep= contains the three axial volumes with coincident split faces.

After export,
[[file:../../bearing_cfd/bearings/conical_journal/geometry/cad.py::def _round_trip_all][=_round_trip_all()=]]
reimports the files and requires:

- the expected number of solids;
- valid and manifold topology for every solid;
- total-volume relative error no greater than =1e-12=.

BREP solid counts and measured geometry form the contract.  XCAF assembly
labels are not required.

* STEP

[[file:../../bearing_cfd/bearings/conical_journal/geometry/cad.py::def _export_step_file][=_export_step_file()=]]
writes millimetres, p-curves, and build123d's highest documented precision
mode.  Reimport requires the expected solid count, valid/manifold solids, and
total-volume relative error no greater than =1e-6=.  Labels are reported but
are not mandatory because individual zone files identify the three bodies.

P-curves and high writer precision do not guarantee that another STEP reader
reconstructs a cone/cylinder intersection identically.  The reimported
topology and measurements determine acceptance.

* Published files

[[file:../../bearing_cfd/bearings/conical_journal/geometry/cad.py::def export_all][=export_all()=]]
stages the following files:

| File | Contents |
|---+---|
| =film_unsplit.brep= | connected fluid solid |
| =film_zones.brep= | three axial fluid solids |
| =film_unsplit.step= | STEP version of the connected fluid solid |
| =film_zones.step= | STEP assembly of the axial zones |
| =ring_A.step=, =hole_band.step=, =ring_B.step= | individual zone STEP files |
| =context_assembly.step= | journal and bushing inspection solids |
| =geometry_half_debug.step= | optional geometry cutaway; not a rotating-CFD domain |
| =film_thickness_map.png= | analytic same-=z= radial-clearance plot |

The command checks BREP first and STEP second.  When BREP passes but STEP does
not:

- the geometry command returns success;
- =params.json= records =step_exchange.status: REJECTED= and the failed
  round-trip measurements;
- accepted geometry contains BREP and diagnostics but no STEP files;
- =--retain-failed-step= writes the STEP batch to
  =<outdir>.rejected-step/= with =REJECTED.json= and =solve_eligible: false=.

A BREP, construction, or in-memory geometry failure still returns status 2
and publishes only a =<outdir>.failed/= diagnostic generation.

* Default result

The current default BREP relative-volume errors are about =1e-13=.  STEP files
containing the feed intersection exceed =1e-6= and are rejected.  Exact values
belong to the generated =params.json= rather than this page.

* Inspection

After generating geometry:

#+begin_src sh
freecad out/conical_journal/geometry/default/film_unsplit.brep
freecad out/conical_journal/geometry/default/film_zones.brep
#+end_src

To inspect a retained rejected STEP batch:

#+begin_src sh
freecad out/conical_journal/geometry/default.rejected-step/film_unsplit.step
#+end_src

Visual inspection cannot resolve the 20 micrometre minimum gap or establish
volume equivalence.  Use =params.json= for those checks.
