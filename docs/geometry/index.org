* Geometry model

The geometry code constructs and validates the exact
lubricant-fluid CAD volume for an eccentric conical journal bearing.  The
CFD body is fluid, not metal.  It contains the complete 360-degree
conical film, the radial feed drilling, and the external inlet extension.
Journal and bushing solids are separate visual context.

The parameter model is
[[file:../../bearing_cfd/bearings/conical_journal/geometry/model.py][=geometry/model.py=]].
OCCT construction and publication are implemented by
[[file:../../bearing_cfd/bearings/conical_journal/geometry/cad.py::def main][=geometry/cad.py: main()=]].  The CAD code uses
build123d algebra mode and OCCT B-rep operations; it does not create a mesh or
run CFD.

* Geometry contract

The CAD stage promises all of the following before an artifact is accepted:

- millimetre construction with exact B-rep solids;
- one connected, valid, manifold full-fluid solid;
- radial-clearance and surface-normal checks kept distinct;
- a feed passage open to the film and ending in one selectable circular inlet;
- three optional axial bodies whose volumes sum to the unsplit fluid volume;
- native BREP and STEP re-import checks performed independently;
- explicit failure and nonzero exit when a mandatory check fails.

The main construction order is visible directly in
[[file:../../bearing_cfd/bearings/conical_journal/geometry/cad.py::def main][main()]].  The validation and export
phases are not optional post-processing: they decide whether output is safe to
publish.

* Tests

The CAD command performs mandatory checks with custom
exceptions and recorded PASS/FAIL entries rather than removable Python
=assert= statements.  Parameter and CAD tests are in
[[file:../../tests/conical_journal/test_geometry_model.py][=test_geometry_model.py=]]
and [[file:../../tests/conical_journal/test_geometry_cad.py][=test_geometry_cad.py=]].
The native BREP then passes an independent Gmsh/OCC preflight in
[[file:../../tests/conical_journal/test_brep_preflight.py][=test_brep_preflight.py=]].
