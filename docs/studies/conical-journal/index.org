Each executable study directory contains a =study.json= manifest with its
question, source revision, commands, external tools, input hashes, and expected
outputs.  Large meshes, time directories, processor partitions, and logs are
generated under =out/= and are not versioned.

* Result labels

- *Pass* means the named numerical or file-format checks succeeded.
- *Unsettled* means a stated convergence, plateau, or conservation check failed.
- *Rejected* means the result violates a physical or numerical acceptance
  condition and is retained only as diagnostic evidence.
- *Unvalidated* means internal checks passed but grid convergence or comparison
  with experimental data is incomplete.
