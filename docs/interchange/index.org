* Scope

Interchange begins after the central-feed Prism6 mesh has passed its geometry,
topology, quality, and serialization checks.  It transfers the exact accepted
coordinates, cells, and physical boundaries into clean solver-neutral files.
It does not read CAD or generate new mesh cells.

The canonical input is =mesh_arrays.npz= together with =manifest.json= and
=mesh_report.json=.  The exporter reconstructs one discrete model and writes
MSH 4.1, MSH 2.2 ASCII, CGNS, and optionally native Fluent ASCII.

* Physical groups

The central-feed model contains one =fluid= volume and six external groups:

- =journal_wall=;
- =bushing_bore_wall=;
- =axial_end_z0=;
- =axial_end_zL=;
- =feed_tube_wall=;
- =pressure_feed=.

The feed mouth is an internal face set and must not appear as a boundary group.

* Validation levels

| Status | Meaning |
|---+---|
| =STATIC_PASS_FLUENT_NOT_RUN= | canonical and format round trips passed; Fluent was not executed |
| =FLUENT_IMPORT_PASS= | a real Fluent process imported, checked, audited, and saved the mesh |
| =FAIL= | a mandatory static check or required live check failed |

Writing a CGNS or Fluent ASCII file is a static operation.  Only the live audit
can establish how Fluent interprets its zones, dimensions, scale, and cell
types.
