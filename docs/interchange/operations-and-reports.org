#+TITLE: Export a Solver-Neutral Mesh
#+UPDATED_AT: [2026-08-02 Sun]
#+STARTUP: overview
#+OPTIONS: toc:2 num:nil

* Generate the source mesh

#+begin_src sh
uv run bearing-cfd conical-journal geometry
uv run bearing-cfd conical-journal mesh brep-preflight --no-gui
uv run bearing-cfd conical-journal mesh central-feed \
  --openfoam skip --no-gui
#+end_src

The default export reads
=out/conical_journal/meshing/central-feed/nGap_08/mesh_arrays.npz=.

* Export without Fluent

#+begin_src sh
uv run bearing-cfd conical-journal export central-feed --fluent skip
#+end_src

The result is =out/conical_journal/interchange/central-feed/=.  Successful
static validation reports =STATIC_PASS_FLUENT_NOT_RUN=.

Use explicit paths to export another accepted central-feed case:

#+begin_src sh
uv run bearing-cfd conical-journal export central-feed \
  --case-dir out/conical_journal/meshing/central-feed/nGap_04 \
  --outdir out/conical_journal/interchange/central-feed-ngap04 \
  --fluent skip
#+end_src

* Export options

| Option | Default | Meaning |
|---+---+---|
| =--coordinate-tolerance= | =1e-14 m= | maximum coordinate-component difference after a round trip |
| =--volume-relative-tolerance= | =1e-12= | reopened total-volume error relative to the canonical cell sum |
| =--fluent skip= | selected above | do not probe or launch Fluent |
| =--fluent auto= | CLI default | run the live audit when PyFluent and a licence are available; otherwise record =NOT_RUN= |
| =--fluent required= | off | fail unless the real Fluent audit passes |
| =--overwrite= | off | permit replacement of an existing export directory |

These tolerances audit serialization.  They do not move nodes, change
connectivity, or heal the source mesh.

* Run the live Fluent audit

On a machine with PyFluent and a suitable Ansys licence:

#+begin_src sh
uv run bearing-cfd conical-journal export central-feed \
  --fluent required --overwrite
#+end_src

Add =--gui= when collecting visual evidence.  The same count, topology,
transcript, and scale checks run in GUI and headless modes.

* Read the reports

#+begin_src sh
uv run python -m json.tool \
  out/conical_journal/interchange/central-feed/interchange_manifest.json

uv run python -m json.tool \
  out/conical_journal/interchange/central-feed/interchange_report.json
#+end_src

The directory contains:

| File | Contents |
|---+---|
| =bearing_prism_gmsh41.msh= | clean Gmsh 4.1 binary mesh |
| =bearing_prism_gmsh22_ascii.msh= | clean Gmsh 2.2 ASCII mesh |
| =bearing_prism.cgns= | one unstructured =PENTA_6= zone with six BC groups |
| =zones.csv= | cell and boundary-face counts by physical name |
| =file_hashes.json= | source and exported-file SHA-256 values |
| =interchange_manifest.json= | concise status, unit, zone, and readiness record |
| =interchange_report.json= | canonical audit and per-format comparisons |
| =run.json= | generation provenance |

A live pass adds =fluent_import_transcript.txt=,
=fluent_import_report.json=, and =bearing_prism_imported.msh.h5=.

* Inspect the files

#+begin_src sh
gmsh out/conical_journal/interchange/central-feed/bearing_prism_gmsh41.msh
#+end_src

For Fluent, import =bearing_prism.cgns= into a 3-D, double-precision meshing or
setup session.  Do not ask Workbench Meshing to edit the volume mesh; doing so
would create a different connectivity.  After a passing import audit, use the
native =bearing_prism_imported.msh.h5= in the supported Fluent workflow.

* Run interchange tests

#+begin_src sh
uv run pytest -q tests/interchange
uv run pytest -q -m integration tests/interchange
#+end_src

The integration command includes the real Fluent test, which skips when the
runtime or licence is unavailable.
