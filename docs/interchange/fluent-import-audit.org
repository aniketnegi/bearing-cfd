* Acceptance boundary

A static CGNS round trip establishes what the local writer produced and read
back.  Fluent has a separate importer, zone model, unit interpretation, licence
boundary, and native mesh representation.  =FLUENT_IMPORT_PASS= therefore
requires [[file:../../bearing_cfd/interchange/fluent_live.py::def run_fluent_import_audit][=run_fluent_import_audit()=]]
to execute against a real Fluent process.

Parser fixtures, mocked sessions, and CGNS round trips cannot produce this
status.

* Runtime policy

| Mode | Behaviour |
|---+---|
| =--fluent skip= | do not import PyFluent or request a licence |
| =--fluent auto= | run when PyFluent and a licence are available; otherwise record =NOT_RUN= |
| =--fluent required= | return failure unless a real import audit passes |

[[file:../../bearing_cfd/interchange/fluent_live.py::def fluent_capability][=fluent_capability()=]]
checks package availability without launching Fluent.  Licence availability is
known only after launch succeeds.

* Session configuration

The audit launches Fluent in:

- meshing mode;
- three dimensions;
- double precision;
- one process;
- GUI or headless mode according to =--gui=.

It imports the CGNS volume mesh, runs mesh and quality checks, captures the
transcript, and queries zone data.  It never enters solution mode, initializes
a flow field, assigns boundary values, or iterates.

* Required comparisons

| Observation | Required result |
|---+---|
| cell zones | exactly one =fluid= zone |
| cell type | Prism6/wedge only |
| boundary zones | exactly the six canonical names |
| boundary counts | exact canonical face count for every patch |
| nodes, faces, and cells | exact canonical totals |
| bounds | canonical metre-scale extents within tolerance |
| total volume | canonical volume within tolerance |
| minimum cell volume | positive |
| maximum skewness | finite and in Fluent's valid range |
| connected regions | one |
| feed mouth | absent from boundary zones |
| mesh check | no invalid connectivity, negative volume, or zero volume |

Missing or merged patches, default/unknown zones, an unexpected region split,
or incomplete transcript metrics are failures.

* Transcript parsing

[[file:../../bearing_cfd/interchange/fluent_live.py::def parse_fluent_transcript][=parse_fluent_transcript()=]]
extracts counts, bounds, volume statistics, skewness, and region count.  If a
Fluent release changes its output and a required value cannot be parsed, the
audit fails.  Update the parser against a saved real transcript before
supporting that release.

* Native mesh promotion

=bearing_prism_imported.msh.h5= is written only after every mandatory check
passes.  It is therefore a promoted output of the audit, not evidence that an
import was merely attempted.

The native mesh still has no material model, boundary values, initialization,
or solution.  Those belong to a solver case.

* Manual equivalent

When PyFluent automation is unavailable:

1. launch Fluent in 3-D double precision;
2. import =bearing_prism.cgns= as a mesh;
3. run *Mesh Check* and *Report Quality*;
4. require one wedge-cell =fluid= zone and the six canonical boundary zones;
5. compare all counts, bounds, volume, minimum cell volume, quality, and region
   count with =interchange_report.json=;
6. verify that no mouth, default, unknown, or merged boundary exists;
7. save =bearing_prism_imported.msh.h5= only after all comparisons pass.

The portable [[file:../../fluent/import_check.jou][=fluent/import_check.jou=]]
runs console import and mesh checks.  It does not decide acceptance or save a
native mesh because those steps require comparison with the canonical report.

* Test

[[file:../../tests/interchange/test_central_feed_export.py::def test_real_fluent_import_when_available][The live integration test]]
is marked =integration= and skips when PyFluent or a licence is unavailable.
A skip leaves the status untested; it is not converted into a pass.
