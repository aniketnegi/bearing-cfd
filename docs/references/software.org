[[file:../../uv.lock][=uv.lock=]] pins the complete environment.  Install it

* CAD and meshing tools

The accepted CAD path uses native OCCT BREP.  STEP is an independently audited
exchange format and is not substituted for a rejected native artifact.  The
relevant implementations are:

- [[file:../../bearing_cfd/bearings/conical_journal/geometry/cad.py][CAD construction and exchange]];
- [[file:../../bearing_cfd/bearings/conical_journal/meshing/brep_preflight.py][Gmsh OCC preflight]];
- [[file:../../bearing_cfd/bearings/conical_journal/meshing/central_feed.py][central-feed geometry audit]].

FreeCAD is useful for manual BREP/STEP inspection but is neither a package
dependency nor an acceptance oracle.  See the
[[https://www.freecad.org/][FreeCAD project site]].

Gmsh generates the Tri3 boundary smoke mesh and the two-dimensional master
surface for the Prism6 central-feed mesh.  The structured Hex8 and swept
Prism6 volume connectivity is assembled in NumPy; these paths do not call
Gmsh's three-dimensional mesh generator.

CGNS export requires =Cgns= in Gmsh's =General.BuildInfo=.  The export is
reopened and checked against the canonical arrays and physical groups.  The
CGNS structures used here are defined by the
[[https://cgns.org/standard/SIDS/hierarchy.html][CGNS hierarchy]] and
[[https://cgns.org/standard/SIDS/grid.html][grid and element]] specifications.

* Optional external runtimes

** Fluent

PyFluent and Ansys Fluent are intentionally absent from =pyproject.toml=.
Static MSH, CGNS, and Fluent-ASCII checks run without proprietary software.
Only a licensed Fluent launch, import, mesh check, count/scale audit, and
native save can produce =FLUENT_IMPORT_PASS=.

Relevant vendor references:

- [[https://fluent.docs.pyansys.com/version/stable/user_guide/session/launching_ansys_fluent.html][PyFluent launch guide]];
- [[https://ansyshelp.ansys.com/public/Views/Secured/corp/v242/en/flu_ug/flu_ug_FileImport.html][Fluent mesh import guide]].

** OpenFOAM

OpenFOAM is not a Python dependency.  The repository contains the native
solver in [[file:../../openfoam/solvers/jfoBearingFoam/][=openfoam/solvers/jfoBearingFoam/=]],
compact reference cases under
[[file:../../cases/conical_journal/openfoam/][=cases/conical_journal/openfoam/=]], and a
build/smoke check:

#+begin_src sh
bash openfoam/check_jfoBearingFoam.sh
#+end_src

Mesh generators treat =gmshToFoam= and =checkMesh= as optional capabilities.
Absence is =SKIPPED= in =auto= mode and fatal in =required= mode.  Reports
record the executable path and detected version because OpenFOAM distributions
and utility behaviour differ.

* Visualization

Gmsh opens =.msh= and =.pos= files.  ParaView opens the generated =.vtu=
files.  Neither viewer determines acceptance; the JSON reports and canonical
arrays do.  See [[file:../operations/visualization.org][Visualization]].
