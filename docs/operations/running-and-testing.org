#+TITLE: Running and Testing
#+UPDATED_AT: [2026-08-02 Sun]
#+STARTUP: overview
#+OPTIONS: toc:2 num:nil

Commands in this page run from the repository root.

* Install dependencies

#+begin_src sh
uv sync --locked
#+end_src

=pyproject.toml= declares the direct dependencies and =uv.lock= pins the full
environment.  All CAD input lengths are millimetres.  Volume-mesh outputs use
metres.

* Run tests

Run the fixture-based suite:

#+begin_src sh
uv run pytest
#+end_src

Run tests that invoke CAD kernels, generate meshes, or probe external
runtimes:

#+begin_src sh
uv run pytest -m integration
#+end_src

Licensed or unavailable runtimes are skipped by their capability checks.  To
run the static checks separately:

#+begin_src sh
uv run ruff check bearing_cfd studies tests
uv run python -m compileall -q bearing_cfd studies tests
#+end_src

* Generate geometry

#+begin_src sh
uv run bearing-cfd conical-journal geometry
#+end_src

The command writes =out/conical_journal/geometry/default/=.  The main files are
=params.json=, =film_unsplit.brep=, =film_zones.brep=, the film-thickness plot,
and =run.json=.

Native BREP is the meshing input.  The current STEP export exceeds its strict
relative-volume tolerance around the feed intersection.  =params.json= records
=step_exchange.status: REJECTED=, and rejected STEP files are not published
with the BREP.  Retain them in a separate diagnostic directory when needed:

#+begin_src sh
uv run bearing-cfd conical-journal geometry --retain-failed-step
#+end_src

This creates =out/conical_journal/geometry/default.rejected-step/=.  Files in
that directory are not mesh inputs.

Override physical dimensions directly on the command.  For example, the
100 mm study geometry uses:

#+begin_src sh
uv run bearing-cfd conical-journal geometry \
  --length 100 \
  --hole-axial-pos 50 \
  --outdir out/conical_journal/geometry/paper-100mm
#+end_src

* Preflight native BREP

The preflight imports native OCCT geometry into Gmsh, fragments the three
axial zones, checks surface and volume classification, and writes an SI copy.
It does not generate mesh elements.

#+begin_src sh
uv run bearing-cfd conical-journal mesh brep-preflight --no-gui
#+end_src

The result is =out/conical_journal/meshing/brep-preflight/=.  Check
=preflight_report.json= before using =film_zones_fragmented.brep= downstream.

* Generate a boundary smoke mesh

#+begin_src sh
uv run bearing-cfd conical-journal mesh surface-smoke --no-gui
#+end_src

This generates first-order Tri3 elements on the boundary only.  A passing
surface-smoke report explicitly contains zero three-dimensional elements; it
is not a solver mesh.

* Generate a volume mesh

The mesh families represent different domains.  Choose the one that matches
the intended boundary condition.

| Method | Domain | Element type | Feed representation |
|---+---+---+---|
| =no-port= | conical film | Hex8 | absent |
| =surface-inlet= | conical film | Hex8 | selected bore faces |
| =body-fitted-inlet= | conical film | Hex8 | conforming circular bore patch |
| =central-feed= | film plus feed passage | Prism6 | resolved tube and open internal mouth |

Generate the no-port reference:

#+begin_src sh
uv run bearing-cfd conical-journal mesh no-port \
  --openfoam skip --no-gui
#+end_src

Generate the mesh-aligned surface inlet:

#+begin_src sh
uv run bearing-cfd conical-journal mesh surface-inlet \
  --openfoam skip --no-gui
#+end_src

Generate one body-fitted circular-inlet case:

#+begin_src sh
uv run bearing-cfd conical-journal mesh body-fitted-inlet \
  --openfoam skip --ansys skip
#+end_src

Generate the resolved central-feed passage after BREP preflight:

#+begin_src sh
uv run bearing-cfd conical-journal mesh central-feed \
  --openfoam skip --no-gui
#+end_src

Each generator checks topology, signed volume, geometry, quality, and file
round trips before publishing its destination.  See
[[file:outputs-and-reports.org][Outputs and reports]] for the files written by
each method.

* Export the central-feed mesh

The exporter reads the accepted =nGap_08/mesh_arrays.npz= from the central-feed
generator and reconstructs clean MSH and CGNS files.  It does not remesh the
geometry.

#+begin_src sh
uv run bearing-cfd conical-journal export central-feed --fluent skip
#+end_src

Use =--fluent required= only on a machine with a licensed Fluent runtime.  A
static round trip is reported as =STATIC_PASS_FLUENT_NOT_RUN=; only a live
import, mesh check, count/scale audit, and native save can produce
=FLUENT_IMPORT_PASS=.

* Run the Python Reynolds--JFO solver

#+begin_src sh
uv run bearing-cfd conical-journal simulate reynolds-jfo \
  --rpm 0 20 496.563 \
  --n-theta 256 \
  --n-axial 80
#+end_src

Each accepted speed becomes a directory containing =summary.json=,
=state.npz=, =jfo_surface.vtu=, and =fields.png=.  The next speed starts from
the preceding fill field.

* Build and check the OpenFOAM JFO solver

With the OpenFOAM Foundation environment available:

#+begin_src sh
bash openfoam/check_jfoBearingFoam.sh
#+end_src

The script builds =jfoBearingFoam= and runs the tracked zero-speed reference
case.  It checks pressure, fill, and conservation before returning success.

* Run study tools

Study drivers use compact tracked inputs but some also require retained
OpenFOAM fields under =out/=.

| Study | Command | Additional requirement |
|---+---+---|
| feed representation | =uv run bearing-cfd conical-journal study jfo-feed-geometry= | none; solved fields are optional |
| guarded continuation parser | =uv run bearing-cfd conical-journal study hydrodynamic-ramp --self-test= | none |
| body-fitted mesh gallery | =uv run bearing-cfd conical-journal study body-fitted-mesh --ansys skip= | Gmsh; OpenFOAM optional |
| JFO checkpoint figures | =uv run bearing-cfd conical-journal study jfo-checkpoint-evidence= | retained OpenFOAM checkpoint fields; FFmpeg for MP4 |
| single-phase figures | =uv run bearing-cfd conical-journal study single-phase-oq90= | ParaView =pvpython= and retained VTK fields |
| four-model summary | =uv run bearing-cfd conical-journal study cavitation-four-track= | retained Tracks B--D =postProcessing= tables |

Each study's =study.json= lists its exact inputs, source hashes, external tools,
and expected outputs.

* Inspect command options

Place =--help= after a complete command:

#+begin_src sh
uv run bearing-cfd conical-journal geometry --help
uv run bearing-cfd conical-journal mesh central-feed --help
uv run bearing-cfd conical-journal simulate reynolds-jfo --help
#+end_src
