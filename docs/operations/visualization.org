#+TITLE: Visualization
#+UPDATED_AT: [2026-08-02 Sun]
#+STARTUP: overview
#+OPTIONS: toc:2 num:nil

Visualization is an inspection aid.  Geometry, topology, scale, and quality
acceptance come from the numerical reports and round-trip checks.

* Preview OCCT geometry

Start an =ocp_vscode= viewer on port 3939, then run:

#+begin_src sh
uv run bearing-cfd conical-journal geometry --preview
#+end_src

The preview shows the connected fluid volume with separate journal and bushing
context.  The journal and bushing are not additional fluid regions.

* Open native BREP in FreeCAD

Generate the geometry first, then inspect the accepted native files:

#+begin_src sh
freecad out/conical_journal/geometry/default/film_unsplit.brep
freecad out/conical_journal/geometry/default/film_zones.brep
#+end_src

=film_unsplit.brep= contains one solid.  =film_zones.brep= contains three
coincident axial solids.  The minimum radial gap is 20 micrometres in the
default case and is not reliably judged by eye.

* Inspect Gmsh OCC preflight

#+begin_src sh
uv run bearing-cfd conical-journal mesh brep-preflight --gui
#+end_src

The GUI opens only after the OCC checks pass.  Surface and volume identities
come from =surfaces.csv=, =volumes.csv=, and =preflight_report.json= rather than
entity numbers shown in the GUI.

* Inspect mesh families in Gmsh

Generate a mesh with =--no-gui= for repeatable batch output, then open its MSH
file explicitly:

#+begin_src sh
gmsh out/conical_journal/meshing/no-port/nGap_08/structured_hex.msh
gmsh out/conical_journal/meshing/surface-inlet/nGap_08/structured_hex.msh
gmsh out/conical_journal/meshing/central-feed/nGap_08/ported_prism.msh
#+end_src

Use the Mesh visibility panel to isolate physical groups.  For the
central-feed mesh, verify that =pressure_feed= is at the remote tube end and
that no =feed_mouth= boundary exists.

The mesh commands also provide focused GUI modes:

#+begin_src sh
uv run bearing-cfd conical-journal mesh no-port \
  --gui --gui-mode quality --quality-view minSICN

uv run bearing-cfd conical-journal mesh surface-inlet \
  --gui --gui-mode inlet

uv run bearing-cfd conical-journal mesh central-feed \
  --gui --gui-mode mouth
#+end_src

GUI launch occurs after publication.  Closing the window or a display-server
failure does not change the accepted mesh files.

* Inspect volume fields in ParaView

Open the VTU volume file:

#+begin_src sh
paraview out/conical_journal/meshing/body-fitted-inlet/volume_hex.vtu
#+end_src

Use *Color By* to inspect =fluent_orthogonal_quality=, signed volume, gap, or
layer index.  Apply *Threshold* to locate cells near a quality limit and
*Slice* or *Clip* to inspect the film thickness.

The selected full-mesh quality figure is versioned at
[[file:../../evidence/conical_journal/oq90_3d/full_3d_fluent_oq_overview.png][=full_3d_fluent_oq_overview.png=]].
Its unwrapped panel projects the minimum through all 12 physical gap cells; it
is not a separate two-dimensional quality calculation.

* Inspect Reynolds--JFO results

The Python solver writes a PNG and VTU for each speed:

#+begin_src sh
paraview out/conical_journal/simulation/reynolds-jfo/20rpm/jfo_surface.vtu
#+end_src

Available cell fields are absolute pressure, gauge pressure, fill fraction,
film thickness, and feed mask.  The PNG uses an unwrapped circumferential axis
with 0 degrees at the minimum gap and 180 degrees at the feed.

Selected animations and figures are under
[[file:../../evidence/conical_journal/][=evidence/conical_journal/=]].  MP4
files are convenient for GitHub downloads; GIF files render directly in more
browsers.

* Exact and exaggerated views

Files below =viz/= may be one of two kinds:

- exact-coordinate subsets used to expose boundaries or cutaways;
- gap-exaggerated copies used only to make a micrometre-scale film visible.

The visualization manifest identifies the type.  Never use an exaggerated
file for mesh conversion, volume measurement, or quality reporting.  Solver
inputs are the full MSH/CGNS/Fluent files named in
[[file:outputs-and-reports.org][Outputs and reports]].
