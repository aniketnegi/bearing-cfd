* Command dispatch

Start with [[file:../../bearing_cfd/cli.py::def main][=bearing_cfd.cli.main()=]].
It selects a bearing, stage, and operation, supplies the default output paths,
and calls the selected module directly.

The common stage lifecycle is:

#+begin_example
parse and validate inputs
        |
construct geometry, mesh, or solution
        |
validate in-memory result
        |
write into a staging directory
        |
reopen and compare serialized files
        |
write run.json and atomically publish
#+end_example

Atomic publication is implemented by
[[file:../../bearing_cfd/artifacts.py::def publish_generation][=publish_generation()=]].

* Central-feed Prism6 mesh

Read this module in three sections:

1. input and native-BREP checks:
   [[file:../../bearing_cfd/bearings/conical_journal/meshing/central_feed.py::def load_contract][=load_contract()=]] and
   [[file:../../bearing_cfd/bearings/conical_journal/meshing/central_feed.py::def validate_native_brep][=validate_native_brep()=]];
2. two-dimensional master topology:
   [[file:../../bearing_cfd/bearings/conical_journal/meshing/central_feed.py::def build_master_mesh][=build_master_mesh()=]];
3. three-dimensional sweep and proof:
   [[file:../../bearing_cfd/bearings/conical_journal/meshing/central_feed.py::def build_prism_mesh][=build_prism_mesh()=]] and
   [[file:../../bearing_cfd/bearings/conical_journal/meshing/central_feed.py::def validate_topology][=validate_topology()=]].

The face census is the key topology check.  External faces have one incident
cell; the feed mouth has two and therefore cannot appear as a boundary patch.

coordinates, so a writer may renumber entities without weakening the audit.

* Reynolds--JFO

Read the Python solver in this order:

1. [[file:../../bearing_cfd/bearings/conical_journal/simulation/reynolds_jfo.py::class Inputs][=Inputs=]]
2. grid construction and film-thickness evaluation
3. conservative pressure/fill assembly
4. [[file:../../bearing_cfd/bearings/conical_journal/simulation/reynolds_jfo.py::def solve_lcp][=solve_lcp()=]]
5. time stepping and convergence policy
6. force, flow, and torque summaries
7. [[file:../../bearing_cfd/bearings/conical_journal/simulation/reynolds_jfo.py::def main][=main()=]]

The short numerical tests are in
[[file:../../tests/conical_journal/test_reynolds_jfo.py][=test_reynolds_jfo.py=]]
and [[file:../../tests/conical_journal/test_jfo_published_benchmark.py][=test_jfo_published_benchmark.py=]].
The independent native implementation is
[[file:../../openfoam/solvers/jfoBearingFoam/jfoBearingFoam.C][=jfoBearingFoam.C=]].
