* Common control pattern

All pipelines follow this shape:

#+begin_src python
inputs = parse_args()
contract = load_and_validate_inputs(inputs)
stage = make_staging_directory(outdir)
artifact = construct(contract)
validate(artifact)
export_to_stage(artifact)
round_trip_and_compare()
atomic_replace_directory(stage, outdir)
#+end_src

Exceptions stop publication.  Mesh generators publish their failure contract;
=run_interchange= discards the failed staging directory and leaves an existing
published output untouched.  The concrete entry points are =run_preflight=,
=run_surface_smoke=, =run_structured=, =run_ported=, and =run_interchange=.

* Solver-neutral interchange path

** Source and pre-write audit

1. [[file:../../interchange/export_solver_neutral.py::class InterchangeInputs][InterchangeInputs]]
2. [[file:../../interchange/export_solver_neutral.py::def load_canonical_case][load_canonical_case]]
3. [[file:../../interchange/export_solver_neutral.py::def audit_canonical][audit_canonical]]

The exporter rebuilds =PrismMesh= from NPZ arrays but does not rebuild geometry
or cells.  =audit_canonical= derives face incidence, patch owners, cell-graph
connectivity, and the geometry summary used by every later comparison.

** Clean model and format writes

4. [[file:../../interchange/export_solver_neutral.py::def write_clean_meshes][write_clean_meshes]]
5. reused [[file:../../meshing/layered_prism_central_feed.py::def add_discrete_prism_model][add_discrete_prism_model]]

Read these together: the first controls clean/no-view writer state; the second
owns the single tested Tri3/Quad4/Prism6 entity registration.

6. [[file:../../interchange/export_solver_neutral.py::def _canonicalize_coordinates][_canonicalize_coordinates]]
