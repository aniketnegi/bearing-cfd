* Output root

Installed commands and repository-local study scripts write below
=out/conical_journal/=:

#+begin_example
out/conical_journal/
├── geometry/
├── meshing/
├── interchange/
├── simulation/
└── studies/
#+end_example

The directory is generated data and is ignored by Git.  Selected plots and
small result tables intended for publication live under
[[file:../../evidence/conical_journal/][=evidence/conical_journal/=]].

The retained current OpenFOAM case is
=out/openfoam_oq90_single_phase/=.  Earlier local generations are grouped by
stage under =out/archive/conical_journal/=.  =MOVED_PATHS.tsv= records their
original relocation.  The current retained and removed artifact inventory is
[[file:../../cases/conical_journal/openfoam/archived/RESULTS.org][the archived OpenFOAM results ledger]].

* =run.json=

Every published generation contains =run.json= with schema version 1.

| Field | Meaning |
|---+---|
| =artifact_id= | SHA-256 identity of the generation record |
| =bearing= | =conical_journal= |
| =stage= and =operation= | producing pipeline operation |
| =case_name= | destination-directory name unless set explicitly |
| =status= | producing stage's result |
| =argv= | command arguments as an array |
| =resolved_inputs.values= | values used by the producer |
| =resolved_inputs.units= | physical units for those values |
| =producer.commit= | Git commit at generation time |
| =producer.dirty= | whether tracked or untracked source changes existed |
| =producer.files= | producing source paths and SHA-256 hashes |
| =upstream_artifacts= | input artifact paths and hashes |
| =tool_versions= | Python and relevant library/runtime versions |
| =outputs= | generated file paths, roles, and SHA-256 hashes |
| =acceptance_status= | Boolean or stage-specific acceptance label |
| =superseded_artifact_id= | identity of the generation replaced at the same path |

=run.json= records provenance.  The stage-specific report remains the source
for geometry, topology, quality, convergence, or solver diagnostics.

* Geometry

Default directory: =out/conical_journal/geometry/default/=

| File | Contents |
|---+---|
| =params.json= | raw inputs, resolved dimensions, geometry measurements, validation records, and BREP/STEP status |
| =film_unsplit.brep= | connected lubricant volume used by the central-feed mesher |
| =film_zones.brep= | three axial lubricant volumes used by preflight |
| =film_thickness_map.png= | analytic same-=z= radial-clearance diagnostic |
| =run.json= | generation provenance and output hashes |

STEP files appear here only when their strict re-import checks pass.  Rejected
STEP files requested with =--retain-failed-step= are written to the sibling
=default.rejected-step/= directory with =REJECTED.json= and =run.json=.

| File | Contents |
|---+---|
| =surface_mesh.msh= | Gmsh 4.1 first-order Tri3 boundary mesh |
| =surface_mesh_ascii.msh= | Gmsh 2.2 ASCII boundary mesh |

* Volume meshes

The no-port, surface-inlet, and central-feed generators write one subdirectory
per through-gap resolution, for example =nGap_08/=.  Their root directory also
contains =run_report.json=, =convergence_report.json=, and =run.json=.

Common case files are:

| File | Contents |
|---+---|
| =mesh_arrays.npz= | canonical coordinates, volume connectivity, boundary faces, and fields |
| =manifest.json= | compact counts, units, and solve-eligibility status |
| =mesh_report.json= | topology, geometry, quality, round-trip, and optional solver-conversion checks |
| =*.msh= | Gmsh 4.1 visualization mesh |
| =*_openfoam.msh= | Gmsh 2.2 ASCII conversion input |
| =volume_*.vtu= | ParaView volume mesh and cell fields |
| =boundary_*.vtu= | external faces and patch identifiers |
| =physical_groups.json= | numeric IDs, names, dimensions, and expected roles |
| =viz/= | cutaways or projected diagnostics; never solver inputs |

The body-fitted generator writes one named case directly below
=out/conical_journal/meshing/body-fitted-inlet/=.  Its
=validation_report.json= includes the full three-dimensional
Fluent-equivalent Orthogonal Quality calculation.  Optional =fluent/= and CGNS
files are derived from the same canonical Hex8 arrays.

* Solver-neutral interchange

Default directory: =out/conical_journal/interchange/central-feed/=

| File | Contents |
|---+---|
| =bearing_prism_gmsh41.msh= | clean Gmsh 4.1 mesh |
| =bearing_prism_gmsh22_ascii.msh= | clean Gmsh 2.2 ASCII mesh |
| =bearing_prism.cgns= | one =PENTA_6= volume zone and named boundary conditions |
| =zones.csv= | cell and boundary-face counts by physical name |
| =file_hashes.json= | source and exported-file SHA-256 hashes |
| =interchange_manifest.json= | concise format and readiness status |
| =interchange_report.json= | canonical audit and per-format round trips |
| =run.json= | generation provenance |

A live Fluent pass additionally writes its transcript, audit report, and
native =.msh.h5= file.  These files are absent from a static-only generation.

* Reynolds--JFO simulation

Default directory: =out/conical_journal/simulation/reynolds-jfo/=

Each speed uses a directory such as =20rpm/=:

| File | Contents |
|---+---|
| =summary.json= | convergence, pressure, fill, flow, force, torque, and acceptance checks |
| =state.npz= | grid coordinates, film thickness, absolute pressure, fill, and feed mask |
| =jfo_surface.vtu= | unwrapped surface fields for ParaView |
| =fields.png= | pressure and fill overview |

The root =ramp_summary.json= lists speeds in continuation order, and =run.json=
records the complete generation.

* Study outputs

Study scripts write to =out/conical_journal/studies/<study>/=.  Expected files
and external inputs are defined by the corresponding
[[file:../../studies/conical_journal/][=study.json=]] manifest.  Generated
figures are not copied into =evidence/= automatically.

OpenFOAM work cases are mutable staged calculations rather than atomically
published directories.  Their logs, checkpoints, source-mesh hash, and stage
marker remain with the ignored work case.  A study renderer writes =run.json=
when it publishes retained figures or compact result tables from that case.

* Failure directories

Geometry and mesh stages may publish =<destination>.failed/= containing a
failure report and =run.json=.  Solver-eligible mesh or exchange files are
removed from these directories.  The previously accepted destination remains
untouched when publication fails.

* Units

| Quantity | Unit |
|---+---|
| CAD and native BREP coordinates | mm |
| mesh-size command arguments | mm |
| canonical volume-mesh coordinates | m |
| surface area in solver reports | m2 |
| cell and total volume | m3 |
| =gap_um= | micrometres |
| pressure | Pa absolute unless a field explicitly says gauge |
