Each arrow crosses a checked file or data boundary.  A stage verifies units,
hashes, geometry, topology, and the fields it consumes rather than trusting a
path or a successful writer call.

* Geometry

[[file:../../bearing_cfd/bearings/conical_journal/geometry/cad.py::def main][The CAD command]]
constructs the connected lubricant volume, splits it into axial zones, and
validates:

- radial and surface-normal clearance;
- connected-solid count and manifold validity;
- full-film and zone volumes;
- feed-inlet location, area, and normal;
- native BREP round trips;
- STEP round trips as a separate interchange check.

Native BREP is the input to Gmsh.  A STEP failure is recorded without changing
the BREP result.  Rejected STEP files are excluded from the accepted geometry
directory.

* BREP preflight

[[file:../../bearing_cfd/bearings/conical_journal/meshing/brep_preflight.py::def run_preflight][=run_preflight()=]]
imports the unsplit and zoned BREP files into Gmsh OCC with automatic healing
disabled.  It fragments the zones, classifies entities from geometry rather
than transient tags, checks shared interfaces, and writes both millimetre and
metre BREP copies.

Preflight establishes that Gmsh sees the intended OCC topology.  It does not
establish that a surface or volume mesh is valid.

* Surface smoke mesh

[[file:../../bearing_cfd/bearings/conical_journal/meshing/surface_smoke.py::def run_surface_smoke][=run_surface_smoke()=]]
generates a first-order Tri3 boundary mesh from the fragmented BREP.  It checks
surface groups, area, element quality, and the absence of 3-D elements.  This
is a boundary-meshing diagnostic, not a solver mesh.

* Volume-mesh branches

** No-port Hex8

[[file:../../bearing_cfd/bearings/conical_journal/meshing/no_port.py::def generate_mesh][=generate_mesh()=]]
evaluates a periodic circumferential/axial/gap grid directly from the analytic
cone and eccentricity equations.  It provides a feed-free Hex8 reference for
geometry, layer, quality, and serialization tests.

** Surface-inlet Hex8

[[file:../../bearing_cfd/bearings/conical_journal/meshing/surface_inlet.py::def build_surface_inlet_mesh][=build_surface_inlet_mesh()=]]
uses the same annular-film topology, clusters coordinates around the feed, and
assigns selected bore faces to =pressure_feed=.  It contains no feed-tube
cells.

** Body-fitted-inlet Hex8

[[file:../../bearing_cfd/bearings/conical_journal/meshing/body_fitted_inlet.py][=body_fitted_inlet.py=]]
replaces the stair-stepped feed patch with a conforming circular O-grid.  Its
quality calculation covers the full three-dimensional Hex8 cells through the
film, not an unwrapped surface projection.

** Central-feed Prism6

[[file:../../bearing_cfd/bearings/conical_journal/meshing/central_feed.py::def build_master_mesh][=build_master_mesh()=]]
triangulates an unwrapped master surface.  [[file:../../bearing_cfd/bearings/conical_journal/meshing/central_feed.py::def build_prism_mesh][=build_prism_mesh()=]]
sweeps the triangles through the conical film and feed tube to construct
Prism6 cells.

The film and tube reuse the same nodes and Tri3 faces at the feed mouth.  Each
mouth face has two incident cells and is absent from the external boundary
groups.  The external =pressure_feed= patch is the remote end of the feed
tube.

* Solver-neutral export

[[file:../../bearing_cfd/bearings/conical_journal/interchange.py::def run_interchange][=run_interchange()=]]
reads the central-feed =mesh_arrays.npz= and its reports.  It reconstructs one
clean discrete mesh and writes:

- Gmsh MSH 4.1;
- Gmsh MSH 2.2 ASCII;
- CGNS with one fluid zone and named boundary conditions;
- native Fluent ASCII when requested.

Every format is reopened and compared with the canonical arrays.  Static file
validation and a live Fluent import have different statuses; see
[[file:../interchange/fluent-import-audit.org][Fluent import audit]].

* Simulation branches

The Python solver in
[[file:../../bearing_cfd/bearings/conical_journal/simulation/reynolds_jfo.py][=reynolds_jfo.py=]]
and native OpenFOAM solver in
[[file:../../openfoam/solvers/jfoBearingFoam/][=jfoBearingFoam=]] operate on reduced
film grids.  They do not consume the three-dimensional volume mesh.  The
body-fitted adapter supplies a conforming surface-feed discretization for
mesh-sensitivity work.

Three-dimensional single-phase and multiphase cases use the Hex8 film mesh and
are maintained as studies with explicit OpenFOAM dictionaries under
[[file:../../studies/conical_journal/][=studies/conical_journal/=]].

* Stage status

| Status | Meaning |
|---+---|
| =PASS= | all mandatory checks for that stage succeeded |
| =FAIL= | at least one mandatory check failed; solver output is not published |
| =REJECTED= | a non-authoritative derivative, such as STEP, failed its own check |
| =STATIC_PASS_FLUENT_NOT_RUN= | file round trips passed; Fluent was not executed |
| =FLUENT_IMPORT_PASS= | Fluent imported, checked, audited, and saved the mesh |
| =SKIPPED= | an optional external tool was unavailable or disabled |

A valid mesh does not imply a valid CFD model, and solver convergence does not
imply agreement with experiment.  Study reports state their numerical and
physical acceptance conditions separately.

* Output publication

New runs use =out/conical_journal/<stage>/...=.  A stage writes into a temporary
sibling directory, completes its checks, creates =run.json=, and atomically
replaces the destination.  Failed attempts cannot leave new files mixed with
the accepted generation.
